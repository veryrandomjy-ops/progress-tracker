📱 手机怎么一键抓取（iOS / 安卓）

① 最简单·所有手机通用：在章节页长按章节标题复制 → 回 App 粘到上方「粘贴页面文字」→「从文字识别」。无需任何设置。

② 苹果 Safari（书签不可用，用「快捷指令」）：iOS 不能用 javascript 书签，解决办法是建一个快捷指令从分享菜单读标题——

• 打开 iPhone「快捷指令」App → 新建空白快捷指令
• 加「获取 [快捷指令输入] 的详细信息」，选「标题」
• 加「URL」动作：填 https://veryrandomjy-ops.github.io/progress-tracker/?t= 然后点空白处插入上面的「标题」变量
• 加「打开 URL」→ 命名保存。下次在章节页点 分享 → 你的快捷指令，自动导入。

③ 安卓 Chrome：电脑 Chrome 把下面书签网址改成代码并同步账号，手机即可用；或用 Firefox/Kiwi（可编辑书签网址）。

书签代码（安卓/电脑用）：在章节页点此书签自动导入。
