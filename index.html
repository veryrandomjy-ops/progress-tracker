📱 手机怎么一键抓取（iOS / 安卓）

① 最简单·所有手机通用：在章节页长按章节标题复制 → 回 App 粘到上方「粘贴页面文字」→「从文字识别」。无需任何设置。

② 苹果 Safari（书签不可用，用「快捷指令」，一次性设置，之后点一下）：

⚠️ 关键：快捷指令必须从 Safari 的「分享」菜单里点来运行（不是从快捷指令 App 里点）。从分享菜单运行时，它才拿得到当前网页；从 App 里点，网页是空的，自然填不进。

⚠️ 在百度 / 微信等 App 的「内置浏览器」里看小说时，分享给快捷指令的是网址而非「网页」，所以「名称」只会是那条网址、抓不到书名。两种解法：① 在百度里点「分享 / ⋯」→「在 Safari 中打开」（或复制链接粘到 Safari 地址栏），再用上面的「记进度」；② 懒得切 Safari，直接用下方「① 复制标题」法——在百度里长按章节标题复制即可，任何 App 内浏览器都通用。若用「记进度」从百度分享，App 会自动把网址当抓取源尝试提取书名，失败再提示你粘贴文字。

  1. 打开「快捷指令」App → 右上角 ＋ → 新建（空白快捷指令）。
  2. 点顶部「快捷指令名称」→ 打开「在共享表单中显示」→ “接受的类型”只勾选「Safari 浏览器网页」，其余全部取消。
  3. 返回编辑页，点「添加操作」→ 搜索「详细信息」（或「网页」）→ 选「获取网页的详细信息」→ 把属性选成「名称」。
    （注意是「名称」，不是「标题」——iOS 没有“标题”这个属性；“名称”就是网页标题）
  4. 再「添加操作」→ 搜索「URL」→ 在框里先输入 https://veryrandomjy-ops.github.io/progress-tracker/?t=，再把光标放到末尾，点键盘上方的「变量」插入第 3 步的「名称」结果。
  5. 先自检：再「添加操作」→ 搜索「显示」→ 选「显示结果」→ 输入选第 4 步的「URL」。
    然后在 Safari 章节页点「分享」→ 选这个快捷指令 → 看弹出的链接：?t= 后面必须有书名（如 ?t=某某小说第123章）。有就说明抓到了；是空的就是没抓到。
  6. 自检通过后，把「显示结果」删掉，换成「打开 URL」→ 输入选第 4 步的「URL」。
  7. 点「完成」→ 给快捷指令改名（如「记进度」）。以后章节页 → 点 分享 → 选「记进度」→ 自动跳回 App 填好书名+章节。

备用方案（如「名称」抓到的是网址而非书名）：用「在网页上运行 JavaScript」→ 脚本只留 const t=document.title;completion(t);（需先在「设置→快捷指令」开「允许运行脚本」），后续步骤同上。

更稳的纯手动方案：新建快捷指令 → 加「获取剪贴板」→ 加「URL」拼 ?t= + 剪贴板变量 → 加「打开 URL」。在 Safari 长按标题复制后运行即可，无需配置共享表单。

③ 安卓 Chrome：电脑 Chrome 把下面书签网址改成代码并同步账号，手机即可用；或用 Firefox/Kiwi（可编辑书签网址）。

书签代码（安卓/电脑用）：在章节页点此书签自动导入。

💡 桌面端更省事：装油猴脚本（Tampermonkey / 暴力猴）。装好后任何小说/剧集页右下角会出现「📌 记进度」按钮，点一下自动填好。安装：点此安装 grab.user.js（需先装好油猴插件；安卓可用 Kiwi / Firefox + 油猴）。
